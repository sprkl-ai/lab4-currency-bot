# Лабораторная работа № 4. Курсы валют

тгбот Трещев Олег Денисович, ИДБ-25-15.

Бот получает справочные курсы и дату курса через [Frankfurter v2](https://frankfurter.dev/). Для Frankfurter ключ не нужен. Настройки каждого пользователя хранятся в локальной базе SQLite.

## Запуск в Windows

Из папки проекта, с установленным Python 3.10 или новее:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` и следуйте подсказкам. Вставьте токен в терминал после приглашения. Ввод скрыт. При необходимости переменную `TELEGRAM_BOT_TOKEN` можно задать в настройках среды запуска.

Для проверки отправьте своему боту `/start`. Бот отвечает, пока программа запущена. Остановка — Ctrl+C.

| Что отправить | Что делает бот |
| --- | --- |
| `USD EUR` или `/rate USD EUR` | Показывает, сколько EUR стоит 1 USD, и указывает дату курса |
| `/set EUR GBP` | Проверяет пару и запоминает её |
| `/my` или кнопка «Мой курс» | Загружает курс сохранённой пары |
| `/help` | Показывает подсказку |

Чтобы проверить API без токена Telegram, выполните `.\.venv\Scripts\python.exe rates.py USD EUR`.
